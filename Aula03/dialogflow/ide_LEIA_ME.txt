━━━ PRIMEIRO PASSO: INSTALACAO ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Abra o terminal no PyCharm (View > Tool Windows > Terminal)
   OU o terminal integrado do VSCode (Ctrl+`)

2. Digite o comando abaixo e pressione Enter:
   pip install -r requirements.txt

   Ou, se preferir instalar um por um:
   pip install colorama
   pip install scikit-learn

━━━ COMO RODAR UM EXEMPLO ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

No PyCharm:
  1. Abra o arquivo desejado (ex: g1_ex01_cumprimentador.py)
  2. Clique no botao verde ▶ Run (canto superior direito)
     OU pressione Shift+F10

No VSCode:
  1. Abra o arquivo desejado
  2. Pressione F5
     OU clique em ▶ Run Python File (canto superior direito)

No Terminal (qualquer editor):
  python g1_ex01_cumprimentador.py

O que acontece ao rodar:
  1. Os testes automaticos aparecem no terminal
  2. O chat abre em seguida — voce ja pode conversar!
  3. Digite "sair" para encerrar o chat

━━━ COMANDOS DO CHAT ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Durante o chat, voce pode digitar:
  sair   → encerra o chat
  reset  → comeca uma nova conversa (limpa o contexto)

━━━ DICA DE DEBUG NO PYCHARM ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

O chat mostra uma linha de debug apos cada resposta:
  [intent: saudacao | certeza: 85% | contexto: nenhum]

Se quiser desativar o debug, chame:
  bot.chat(debug=False)

Se quiser testar uma frase sem abrir o chat:
  r = bot.detectar("oi tudo bem")
  print(r)
